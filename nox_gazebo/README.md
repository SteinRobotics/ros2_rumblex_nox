# Nox simulation

Use `ros2 launch nox_bringup test_gazebo_launch.py` for the composed mesh simulation.
Standalone `simulation_gazebo.launch.py`, `simulation_mesh.launch.py` and
`visualization_rviz.launch.py` are also available. All use Nox models and controllers.
See [launch commands](../README_LAUNCH.md) and [resource limits](../nox_doc/BUILD_AND_TEST.md).
